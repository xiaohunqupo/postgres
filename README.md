ZWSQL Database Management System
================================

This directory contains the source code distribution of **ZWSQL**, a
database management system derived from [PostgreSQL](https://www.postgresql.org/).

ZWSQL builds on PostgreSQL's advanced object-relational engine (extended
SQL, transactions, foreign keys, subqueries, triggers, user-defined types
and functions, and C language bindings) and adds enhancements aimed at
low-concurrency, high-volume workloads, deep relational queries, spatial
data, and industrial 3D scenarios. See [ZWSQL_DERIVATION.md](ZWSQL_DERIVATION.md)
for lineage, copyright scope, and licensing details.

**Relationship to PostgreSQL:** ZWSQL is a derivative work based on
PostgreSQL. The original PostgreSQL copyright and license terms remain in
full force; see [COPYRIGHT](COPYRIGHT) and [ZWSQL_DERIVATION.md](ZWSQL_DERIVATION.md).

Copyright and license information for this distribution can be found in

based on can be found at <https://www.postgresql.org/docs/18/>. In
particular, information about building from source can be found at
<https://www.postgresql.org/docs/18/installation.html>.

The latest upstream PostgreSQL releases may be obtained at
<https://www.postgresql.org/download/>. For more information about
